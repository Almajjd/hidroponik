# **App Name**: HydroControl

## Core Features:

- Real-time Status Dashboard: Real-time dashboard displaying pH, EC/TDS, water temperature, water level, and light intensity with color-coded indicators for optimal, warning, and critical states.
- Device Control: Controls for water pump, grow lights (ON/OFF buttons), automated scheduling for pumps and lights, and manual/automatic nutrient dosing controls.
- Data Monitoring & History: Interactive graphs for historical data tracking (pH, EC, temperature) with selectable time ranges and summary tables.
- Notifications/Alerts: System for displaying notifications for parameters exceeding critical thresholds, including a notification history.
- User Management: Simple login/registration page with password reset options. Only authenticated users can access the dashboard.

## Style Guidelines:

- Primary color: Teal (#008080) to represent water and plant health.
- Secondary color: Light Gray (#D3D3D3) for a clean and modern look.
- Accent color: Lime Green (#32CD32) to highlight important data and controls.
- Font: Roboto for a clear, readable, and mobile-friendly experience.
- Simple, intuitive icons representing sensors, devices, and alerts.
- Responsive layout optimized for mobile devices, ensuring a native app-like experience.
- Subtle animations and transitions to provide feedback and enhance user experience without being distracting.
